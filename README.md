# Phishing URL Behaviour Classification

## 1. Project Overview

This project develops a machine learning system
for classifying URLs into phishing and legitimate
categories.

## 2. Problem Statement

Phishing URLs can be designed to deceive users
into visiting malicious websites.

The objective is to classify URL behaviour using
machine learning techniques.

## 3. Dataset

Dataset:
PhiUSIIL Phishing URL Dataset

Source:
UCI Machine Learning Repository

## 4. Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## 5. Machine Learning

- Logistic Regression
- Feature Selection
- Train/Test Split
- Standardization

## 6. Evaluation

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

## 7. Application

A Streamlit application is developed
for phishing URL classification.
